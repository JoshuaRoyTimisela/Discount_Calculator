# Discount Calculator — Python

Project untuk tahap Advanced Teacher Candidate Koding Next.

## Fitur
- Input harga awal
- Input persentase diskon
- Input jumlah barang
- Menghitung total harga setelah diskon
- Validasi input
- Tombol Calculate
- Tekan Enter untuk menghitung

## Rumus
Subtotal = Original Price × Quantity

Discount Amount = Subtotal × (Discount / 100)

Final Price = Subtotal - Discount Amount

## Cara menjalankan

Pastikan Python 3 sudah terinstall, lalu jalankan:

```bash
python discount_calculator.py
```

Tkinter biasanya sudah termasuk dalam instalasi Python di Windows.

## Contoh
Harga = Rp20.000  
Quantity = 2  
Diskon = 25%

Subtotal = Rp40.000  
Diskon = Rp10.000  
Final Price = Rp30.000
